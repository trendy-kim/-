# 법인카드 집근처 사용 분석

법인카드 이용내역(엑셀/CSV)에서 집 반경 내 사용, 이상징후를 탐지하고 경영진 보고서를 만드는 정적 웹앱입니다. 서버 없이 브라우저에서만 동작합니다.

- 지도·주소검색: 카카오맵 JavaScript 키 (화면 설정 탭에서 직접 입력)
- AI 요약·보고서: Gemini API 키 (화면 설정 탭에서 직접 입력, 선택 사항)
- 키와 집주소는 각자 브라우저에만 저장되며 저장소에는 포함되지 않습니다.
- 카드 내역 파일(xlsx/csv)은 `.gitignore`로 커밋이 차단됩니다.

로컬 실행: `start.bat` 더블클릭 → http://localhost:8080
배포·보안 안내: [DEPLOY.md](DEPLOY.md)
