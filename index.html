이용자별 집주소

데이터의 이용자명이 자동으로 나열됩니다. 주소를 입력하고 [검색]을 누르거나, [지도에서 선택]으로 직접 위치를 찍으세요. 집주소는 이 브라우저에만 저장됩니다. 카드 내역은 탭을 닫으면 사라지고(카드번호는 뒤 4자리만 보관), 집주소·좌표는 이 PC에 남으니 공용 PC에서는 사용 후 [설정 > 모든 저장값 초기화]를 누르세요.

일괄 등록

한 줄에 이용자명, 집주소 (쉼표 또는 탭 구분). 엑셀에서 두 열을 복사해 붙여넣어도 됩니다.

이상징후 탐지 결과

대시보드의 이용자·기간 필터가 그대로 적용됩니다. 규칙 기반 탐지이며 부정 확정이 아니라 소명 확인 대상입니다.

AI 요약 (Gemini)

탐지 결과의 집계값만 Gemini로 전송합니다. 카드번호·집주소는 전송하지 않으며, 직원명은 가명(직원01…)으로 바꿔 보냅니다(설정에서 변경).

경영진 보고서 작성

카카오맵 연결

  1. 카카오 개발자센터에서 애플리케이션을 만듭니다.
  2. [앱 설정 > 플랫폼 > Web]에 사이트 도메인 지금 접속 중인 주소 를 등록합니다. (주소창에 보이는 것과 글자 그대로, 포트 포함)
  3. [카카오맵] 사용 설정을 ON으로 켭니다. (꺼져 있으면 지도·주소검색이 동작하지 않습니다)
  4. [앱 키]의 JavaScript 키를 위에 붙여넣고 저장합니다. 저장하면 페이지가 새로고침됩니다.

Gemini 연결 (AI 요약·보고서)

  1. Google AI Studio에서 API 키를 발급받아 위 칸에 붙여넣고 아래 [저장]을 누릅니다.
  2. 키는 이 PC 브라우저에만 저장되며, Gemini 호출 외에는 사용되지 않습니다. 공용 PC에서는 사용 후 [모든 저장값 초기화]를 누르세요.
  3. 전송되는 정보: 집계 통계, 이상징후 요약, 예시 거래(일자·시간·가맹점·업종·금액·거리). 전송 안 됨: 카드번호, 집주소, 좌표, 전체 거래 원본.
  4. 회사 정책상 외부 AI로 가맹점·금액 정보를 보내면 안 되는 경우 사용하지 마세요. 키를 비워두면 AI 기능은 꺼지고 나머지는 그대로 동작합니다.
